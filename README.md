# MT Personal Agent — Arman

Chat-first Bengali personal work agent for one verified owner. It supports durable conversations, routines, reports, memory, original photo/video publishing, server push, Gmail, WhatsApp, Telegram, two typed website bridges and guarded repository PR/deployment workflows.

Start with `DEPLOYMENT-CHECKLIST-BN.md`. Full configuration details are in `GUIDE-BN.md`. Run `npm ci` then `npm run build` before deployment.

No credentials are included in this repository. Keep `.env` and service-account files out of Git.
